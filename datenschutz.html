Datenschutzerklärung – ICH Mail

Stand: 29. Oktober 2026

1. Zweck

ICH Mail ist eine privat entwickelte Anwendung zur Analyse und Organisation eigener Gmail-Postfächer. Sie wird ausschliesslich für persönliche Zwecke verwendet.

2. Zugriff auf Google-Daten

Die Anwendung verwendet die Gmail API mit der Berechtigung gmail.readonly. Sie kann E-Mails lesen, jedoch keine Nachrichten versenden, verändern oder löschen.

3. Verarbeitung und Speicherung

E-Mail-Daten werden lokal auf den autorisierten Geräten verarbeitet. OAuth-Zugangsdaten werden lokal verschlüsselt gespeichert.

Der Bearbeitungsstatus von E-Mail-Konversationen wird im privaten Obsidian-Vault gespeichert und zwischen den eigenen Geräten synchronisiert. Dabei werden keine vollständigen E-Mail-Inhalte im Statusprotokoll gespeichert.

4. Weitergabe

Es erfolgt keine Weitergabe von Gmail-Daten an Werbetreibende oder Datenhändler. Die Anwendung verwendet Gmail-Daten nicht für Werbung oder das Training von KI-Modellen.

5. Widerruf

Der Zugriff kann jederzeit in den Sicherheitseinstellungen des Google-Kontos widerrufen werden.

6. Google API Services User Data Policy

Die Nutzung der über Google APIs erhaltenen Informationen erfolgt gemäss der Google API Services User Data Policy, einschliesslich der Limited Use Requirements.
